# Security Policy

## Supported Versions

The following versions of **MyTTSApp** are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| dev     | No        |
| older releases | No |

## Reporting a Vulnerability

If you discover a security issue in **MyTTSApp**, please report it responsibly.

Please do **not** open a public issue for security vulnerabilities.

Instead, report it privately with the following details:

- Description of the issue
- Steps to reproduce
- Affected version or branch
- Impact of the vulnerability
- Suggested fix, if available

## Response Process

After a report is received, the project maintainer will aim to:

- Acknowledge the report within 7 days
- Investigate and validate the issue
- Work on a fix for confirmed vulnerabilities
- Release a patch or mitigation when possible

## Disclosure Policy

Please allow time for the issue to be reviewed and fixed before making any public disclosure.

Responsible disclosure helps protect users of this project.

## Security Best Practices

Users and contributors should:

- Keep Android Studio and dependencies updated
- Avoid committing secrets, API keys, or credentials
- Review third-party libraries before adding them
- Use secure network communication where applicable
- Test input handling and permission usage carefully

## Scope

This policy applies to:

- Source code in this repository
- Build configuration files
- Dependency and package updates
- Application logic related to translation, text input, and text-to-speech features
